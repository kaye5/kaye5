## Hi there 👋 
👋 I'm Kevin — a backend-leaning Software Engineer who speaks fluent Go and JavaScript (and occasionally argues with them too).

I spend my days building web stuff that’s scalable, reliable, and won’t catch fire when traffic spikes. I'm all about clean architecture, efficient code, and learning cool things that make systems better (and my life easier).

I've got a decent handle on cloud infrastructure, so I know how to launch apps into the sky without them crash-landing.

🌱 Lately, I’ve been diving into the world of IoT, where toasters talk to clouds and fridges get smarter than me.

Always learning, sometimes debugging, occasionally celebrating when things work on the first try.

### Jokes for the day
I firmly believe in testing... in production — because nothing says “battle-tested” like a user finding that one edge case QA never saw 😬.
> 💡 Motto: "Ship it. Then fix it. Then pretend it worked all along."
